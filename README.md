# INA226_Monitor

INA226-1A（M5Stack Unit INA226-1A）＋ Arduino UNO で測った電流・電圧を PC でリアルタイムに表示し、
測定後に CSV・グラフ画像（PNG）・メモ（TXT）を保存する Windows 用ソフトです。
仕様は [SPEC.md](SPEC.md)（v0.3）を参照してください。今回は機能フェーズの実装で、配色は標準のままです。

## 使い方
1. Arduino を USB で PC に接続し、`INA226_Monitor.exe` を起動する（管理者権限は不要）。
2. 上部の「COM ポート」で Arduino のポートを選ぶ（例：`COM7 - Arduino Uno`）。見つからなければ USB を確認して「更新」。
3. 左側の「測定情報」に基板情報・測定対象・測定者を入力する（任意。前回の値が入っています）。
4. 必要なら負荷を外した状態で「ゼロ点補正」を押す（約 1〜3 秒）。補正値はアプリを閉じるまで有効です。
5. 「開始」を押す。測定日時と出力ファイル名が更新され、グラフと数値が 200 ms ごとに更新されます。
   グラフの表示範囲は「10 秒 / 60 秒 / 300 秒 / 全体」で切り替えます。
6. 「停止」を押す。グラフは全体表示になります（マウスのホイールやドラッグで拡大・移動できます）。
7. 必要ならメモを入力し、出力ファイル名と保存先を確認して「保存」を押す。
8. 測定対象を付け替えて 5〜7 を繰り返す。

- 出力ファイル名は「自動生成」で `<測定日時>_<測定対象>_<基板情報>_<測定者>` に作り直せます。
  手で書き換えた場合は、開始を押しても変わりません（「自動生成」を押すと自動に戻ります）。
- 「PC の日時を出力する」をオンにすると、CSV の 2 列目に PC の受信時刻（pc_time）が入ります。

## 配線と Arduino スケッチの書き込み
配線（Arduino UNO と Unit INA226-1A の Grove ケーブル）：

| ケーブルの色 | Arduino UNO |
|---|---|
| 黒 | GND |
| 赤 | 5V |
| 黄 | SDA（A4） |
| 白 | SCL（A5） |

測定する電流は INA226-1A の測定側端子（シャント 80 mΩ、最大 ±1 A）に直列に入れます。

スケッチの書き込み：
1. [Arduino IDE](https://www.arduino.cc/en/software) をインストールする。
2. `firmware/ina226_logger/ina226_logger.ino` を開く。
3. 「ツール」→「ボード」で **Arduino Uno**、「ポート」で Arduino の COM ポートを選ぶ。
4. 「書き込み」を押す。
5. 確認したい場合はシリアルモニタ（115200 bps）で `time_ms,bus_V,shunt_uV,current_mA` と数値の行が流れることを見る。
   **確認後はシリアルモニタを閉じてください**（開いたままだと本ソフトからポートを開けません）。

平均回数・変換時間・送信周期を変えたいときはスケッチ側を書き換えます（本ソフトからは設定しません）。

## 出力ファイル
保存先には、出力ファイル名（基名）に拡張子を付けたファイルができます。

| ファイル | 出力条件 | 内容 |
|---|---|---|
| `<基名>.csv` | 常に | `elapsed_s,(pc_time),bus_V,current_mA,power_mW,mAh`。UTF-8（BOM 付き）・CRLF なので Excel でそのまま開けます |
| `<基名>.png` | 常に | 1600×900。上段 電流、下段 電圧。タイトルに測定情報、下部に積算 mAh・測定時間・サンプル数・ゼロ点補正値 |
| `<基名>.txt` | メモが空白以外を含むとき | 測定情報・測定条件と、メモの内容 |

- current_mA・power_mW・mAh はゼロ点補正後の値です。
- 同じ基名のファイルが 1 つでもあれば `_2`, `_3` … を付けて、全ファイルを同じ基名にそろえます。

設定・ログ・一時ファイルの場所：

| 用途 | 場所 |
|---|---|
| 前回値（ポート・測定情報・保存先・PC 日時チェック） | `%APPDATA%\INA226_Monitor\settings.json` |
| ログ（エラー・警告。最大 1 MB × 3 世代） | `%APPDATA%\INA226_Monitor\app.log` |
| 測定中の一時ファイル | `%LOCALAPPDATA%\INA226_Monitor\recovery\` |

## 異常時の動作
| 状況 | 動作 |
|---|---|
| ポートが他のソフトで使用中 | 「COMx を開けません。シリアルモニタなど他のソフトを閉じてください」 |
| 開始後 5 秒間データが来ない | ステータス欄に「データが届いていません」（測定は継続） |
| 測定中に USB が抜けた | 自動停止して「Arduino との接続が切れました」。そこまでのデータは保存できる |
| Arduino がリセットされた | 区切りをまたぐ区間は積算せずに継続。ステータス欄に表示 |
| 保存先に書き込めない | 「<ファイル名> に書き込めません…」。データは残るので保存し直せる |
| 未保存のまま開始・終了 | 「保存されていないデータがあります。保存しますか？」 |
| 異常終了・電源断 | 測定中は 60 秒ごとに一時ファイルへ追記。次回起動時に復旧するか確認し、`<測定日時>_recovered.csv` として保存できる |

## 開発者向け（実行・テスト・模擬シリアル）
Python 3.11 以上。

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
python -m ina226_monitor --mock
```

`--mock` を付けると、実機なしで動かせる模擬シリアルがポート一覧に出ます。

| ポート | 内容 |
|---|---|
| MOCK1 | 負荷あり（約 15〜35 mA ＋ 7 秒ごとに 120 mA のパルス、約 3.7 V） |
| MOCK2 | 無負荷（-0.1 mA 前後。ゼロ点補正の確認用） |
| MOCK3 | 20 秒後に USB が抜ける |
| MOCK4 | 30 秒ごとに Arduino がリセットされる |

その他のオプション：
- `--mock-speed 10`：模擬シリアルを 10 倍速で動かす。
- `--mock-preload 576000`：8 時間分（576,000 サンプル）の模擬データを「停止後」の状態で読み込む（AC-13 の手動確認用）。

テスト：

```bat
python -m pytest -q
```

GUI 以外のモジュールは GUI なしでテストできます。GUI の結合テスト（`tests/test_gui_smoke.py`）も画面なし（offscreen）で動きます。

| テスト | 内容 | 受け入れ基準 |
|---|---|---|
| `test_protocol.py` | 行の分割・判定 | AC-03 |
| `test_measurement.py` | mAh・電力・ゼロ点補正・リセット | AC-05, 06, 22 |
| `test_zero_cal.py` | 補正値の計算・異常時 | AC-22 |
| `test_filename.py` | ファイル名生成 | AC-18 |
| `test_storage.py` | CSV・TXT 出力、pc_time 列、同名時の `_2`、書き込み失敗 | AC-15, 20 |
| `test_recovery.py` | 一時ファイルの追記・再試行・復旧 | F-10, F-11 |
| `test_png_and_performance.py` | PNG、576,000 サンプルの表示・保存時間 | AC-13 |
| `test_gui_smoke.py` | 模擬シリアルで開始・停止・保存、USB 抜け、ゼロ点補正、未保存確認 | AC-08, 11, 12, 17, 19, 23 |

## exe のビルド
Windows で `build.bat` を実行します。

```bat
build.bat
```

`.venv` を作って依存パッケージを入れ、テストを実行してから PyInstaller でビルドし、
`dist\INA226_Monitor\`（フォルダ一式）と `INA226_Monitor_v1.0.0.zip` を作ります。
配布は zip を渡し、受け取った人は展開して `INA226_Monitor.exe` を起動します（インストール不要）。

GitHub に push すると `.github/workflows/build-windows.yml` が Windows 上でテストとビルドを行い、
フォルダ一式を `INA226_Monitor-windows` というアーティファクトとして残します。

  zero_cal.py      ゼロ点補正の受信と補正値の計算
  filename.py      出力ファイル名の生成
  formatting.py    数値・日時・CSV 行の書式
  storage.py       CSV・TXT の保存、PNG のタイトル・注記
  png_export.py    保存用グラフ画像の描画
  recovery.py      一時ファイルへの追記（別スレッド）と復旧
  decimate.py      表示用の間引き
  settings.py / paths.py / logsetup.py
  gui/main_window.py  メインウィンドウ
  gui/plot_panel.py   リアルタイムグラフ

追加ライブラリ：仕様の 4 つ（PySide6・pyqtgraph・pyserial・numpy）以外は使っていません。
開発用に pytest（テスト）と PyInstaller（exe 化）を使います（`requirements-dev.txt`）。

## 仕様の解釈・補足
仕様に明記がない点は次のように実装しました。

- **経過時間・測定時間**：Arduino の time_ms から算出（最初のデータ行を 0）。画面・PNG・TXT とも秒未満は切り捨て。
  Arduino のリセット後は、リセット前後の PC 受信時刻の差で経過時間をつないでいます。
- **ポートを開いた直後 0.3 秒のデータ行**は、Arduino がリセットされる前の残りの可能性があるため取り込みません
  （受信サンプル数にも数えません）。
- **ゼロ点補正値**は 20 行の平均を 0.001 mA 単位に丸めた値です（記録される値と実際に差し引く値を一致させるため）。
  測定データには開始時点の補正値が使われ、停止後に補正し直しても保存内容は変わりません。
- **「データが届いていません」**は開始後に加え、測定中にデータが 5 秒途切れたときにも表示します。
- **保存先フォルダと「PC の日時を出力する」**は左側の「出力」欄に置きました。
- **保存時のファイル名**に使えない文字が入っていた場合は `_` に置き換えて保存します。
- **復旧した CSV を保存したあと**は、その一時ファイルを削除します（次回起動時に同じ確認が出ないように）。
  データ行が 1 行も無い一時ファイルは確認を出さずに削除します。
- **測定中にウィンドウを閉じる**と未保存確認を出し、「保存」「保存しない」なら測定を止めてから処理します。「キャンセル」なら測定を続けます。
- 一時ファイル名が重なった場合（同じ秒に 2 回開始など）は `_2` を付けます。
